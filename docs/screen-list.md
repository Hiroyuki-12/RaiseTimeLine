# 画面一覧

## 画面構成

| 画面ID | 画面名 | URL | 認証要否 | 概要 |
|--------|--------|-----|----------|------|
| SCR-01 | ログイン画面 | `/login` | 不要 | メール/パスワードでログイン |
| SCR-02 | ユーザー登録画面 | `/register` | 不要 | 新規アカウント作成 |
| SCR-03 | タイムライン画面 | `/` | 必要 | 全体／フォロー中タブ切り替えの投稿一覧 |
| SCR-04 | 投稿詳細画面 | `/posts/:postId` | 必要 | 投稿本文＋コメント一覧 |
| SCR-05 | プロフィール画面 | `/users/:username` | 必要 | ユーザー情報・投稿一覧・フォロー操作 |
| SCR-06 | フォロー一覧画面 | `/users/:username/follows` | 必要 | フォロー中／フォロワー一覧（タブ切り替え） |
| SCR-07 | ユーザー検索画面 | `/search` | 必要 | ユーザー名検索・結果一覧 |

---

## 画面遷移図

```
[未認証]
  SCR-01 ログイン画面
    ├─ ログイン成功     → SCR-03 タイムライン画面
    └─ 新規登録リンク   → SCR-02 ユーザー登録画面

  SCR-02 ユーザー登録画面
    ├─ 登録成功         → SCR-03 タイムライン画面
    └─ ログインリンク   → SCR-01 ログイン画面

[認証済み]
  SCR-03 タイムライン画面（メイン）
    ├─ 投稿カードクリック        → SCR-04 投稿詳細画面
    ├─ ユーザー名/アバタークリック → SCR-05 プロフィール画面
    ├─ コメントアイコンクリック  → SCR-04 投稿詳細画面
    ├─ 検索アイコンクリック      → SCR-07 ユーザー検索画面
    └─ 自分のアバタークリック    → SCR-05 プロフィール画面（自分）

  SCR-04 投稿詳細画面
    ├─ ユーザー名/アバタークリック → SCR-05 プロフィール画面
    ├─ コメントのユーザー名クリック → SCR-05 プロフィール画面
    └─ 戻るボタン                 → SCR-03 タイムライン画面

  SCR-05 プロフィール画面
    ├─ フォロー数クリック   → SCR-06 フォロー一覧画面（フォロー中タブ）
    ├─ フォロワー数クリック → SCR-06 フォロー一覧画面（フォロワータブ）
    ├─ 投稿カードクリック   → SCR-04 投稿詳細画面
    └─ 戻るボタン          → 直前の画面

  SCR-06 フォロー一覧画面
    ├─ ユーザー行クリック → SCR-05 プロフィール画面
    └─ 戻るボタン        → SCR-05 プロフィール画面

  SCR-07 ユーザー検索画面
    └─ ユーザー行クリック → SCR-05 プロフィール画面
```

## 共通ナビゲーション（認証済み画面共通）

認証済みの全画面に以下のナビゲーションバーを表示する：

| 要素 | 動作 |
|------|------|
| アプリロゴ | SCR-03 タイムライン画面へ遷移 |
| 検索アイコン | SCR-07 ユーザー検索画面へ遷移 |
| 自分のアバター | SCR-05 プロフィール画面（自分）へ遷移 |
| ログアウトボタン | ログアウト → SCR-01 ログイン画面へ遷移 |
| 投稿作成ボタン | 投稿作成モーダルを開く |
