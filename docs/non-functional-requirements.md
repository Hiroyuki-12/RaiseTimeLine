# 非機能要件

## パフォーマンス

| 項目 | 要件 |
|------|------|
| タイムライン読み込み時間 | 通常環境で 2 秒以内 |
| 投稿・いいね・コメントのレスポンス | 1 秒以内 |
| 画像アップロード | 5MB 以内のファイルを 5 秒以内に完了 |
| ユーザー検索（インクリメンタル） | 入力から結果表示まで 500ms 以内 |

## 可用性

| 項目 | 要件 |
|------|------|
| 目標稼働率 | 学習用途のため特定の SLA は設けない |
| 障害時の対応 | 手動での EC2 再起動・RDS フェイルオーバーで対応 |

## セキュリティ

| 項目 | 要件 |
|------|------|
| 通信 | HTTPS (TLS 1.2 以上) を強制。HTTP は 443 へリダイレクト |
| 認証 | JWT トークン（有効期限 24 時間）を使用 |
| パスワード | BCrypt でハッシュ化して保存。平文保存は禁止 |
| SQL インジェクション | JPA / Prepared Statement で防止 |
| XSS | React の JSX エスケープ機能で防止。ユーザー入力の直接 HTML 挿入は禁止 |
| CORS | バックエンドはフロントエンドのオリジンのみ許可 |
| S3 アクセス | IAM Role 経由のみ。バケットはパブリックアクセスをブロック |
| 機密情報 | 環境変数で管理。コードへの直接記載・コミットは禁止 |

## スケーラビリティ

| 項目 | 要件 |
|------|------|
| 対象ユーザー数 | 学習用途のため小規模（数十名程度）を想定 |
| 水平スケール | 現構成では単一 EC2。負荷増大時は対応外 |

## 保守性

| 項目 | 要件 |
|------|------|
| コード管理 | Git（GitHub）でバージョン管理 |
| DB マイグレーション | Flyway によるスキーマ変更管理 |
| ログ | バックエンドは構造化ログ（ECS 形式の JSON）で標準出力に出す。詳細は [logging-spec.md](logging-spec.md) を参照 |
| デプロイ | Terraform + GitHub Releases による再現可能なデプロイ |

## 互換性

| 項目 | 要件 |
|------|------|
| 対応ブラウザ | Chrome 最新版・Firefox 最新版・Safari 最新版 |
| モバイル対応 | レスポンシブ対応（Tailwind CSS によるモバイルファースト設計） |
| 画面解像度 | 320px 〜 1920px |
