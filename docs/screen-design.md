# 画面設計書

## SCR-01 ログイン画面 {#scr-01}

**URL**: `/login`  
**認証**: 不要

### レイアウト

```
┌─────────────────────────────────────┐
│                                     │
│          RaiseTimeLine              │  ← アプリロゴ
│                                     │
│       RaiseTimeLineにログイン        │
│                                     │
│  ┌───────────────────────────────┐  │
│  │  メールアドレス               │  │  ← テキスト入力
│  └───────────────────────────────┘  │
│  ┌───────────────────────────────┐  │
│  │  パスワード                   │  │  ← パスワード入力
│  └───────────────────────────────┘  │
│                                     │
│  ┌───────────────────────────────┐  │
│  │         ログイン              │  │  ← ログインボタン（Primary）
│  └───────────────────────────────┘  │
│                                     │
│   アカウントをお持ちでない方は 新規登録  │  ← SCR-02へのリンク
│                                     │
└─────────────────────────────────────┘
```

### 項目定義

| 要素 | 種別 | 説明 |
|------|------|------|
| メールアドレス | input[type=email] | 必須 |
| パスワード | input[type=password] | 必須 |
| ログインボタン | button | クリックで認証処理を実行 |
| 新規登録リンク | link | SCR-02へ遷移 |

### エラー表示

- 認証失敗時：フォーム上部に「メールアドレスまたはパスワードが正しくありません」を表示

| パスワード（確認） | input[type=password] | パスワードと一致 |

## SCR-03 タイムライン画面 {#scr-03}

**URL**: `/home`  
**認証**: 必要

### レイアウト

```
┌──────────────────┬──────────────────────────────────┐
│  RTL             │  ホーム                           │  ← ページタイトル
│                  ├──────────────────────────────────┤
│  🏠 ホーム       │  [全員]  [フォロー中]             │  ← タブ切り替え
│  🔍 検索        ├──────────────────────────────────┤
│  👤 プロフィール  │  [テ]  いまどうしてる？...        │  ← コンパクト投稿欄
│                  ├──────────────────────────────────┤
│  ┌───────────┐  │  [テ] 表示名 @username · 3分前 ✏🗑 │
│  │  投稿する  │  │  投稿テキストが表示される          │
│  └───────────┘  │  🤍 0   💬 0                       │
│                  ├──────────────────────────────────┤
│                  │  [S] 表示名2 @username2 · 1時間前  │
│  [テ] 表示名     │  別の投稿テキスト                  │
│  @username       │  🤍 0   💬 0                       │
│  [ログアウト]    ├──────────────────────────────────┤
│                  │  さらに読み込む / すべて読込済み   │
└──────────────────┴──────────────────────────────────┘
```

**左サイドバー**:
- RTL ロゴ
- 🏠 ホーム（現在のページ）
- 🔍 検索（今後実装）
- 👤 プロフィール（今後実装）
- 「投稿する」ボタン → 投稿作成モーダルを開く
- ログインユーザーのアバター・表示名・@handle
- ログアウトボタン

**投稿カード**:
- カラーアバター（username からハッシュで色決定、イニシャル文字表示）
- 表示名 + @handle + 相対時間（3分前、1時間前、1日前 など）
- 投稿本文
- 🤍 いいね数（現時点は0固定）・💬 コメント数（現時点は0固定）
- 投稿者本人のみ: ✏️ 編集ボタン・🗑️ 削除ボタン

### 投稿作成モーダル

```
┌────────────────────────────────────┐
│  [✕]  新しい投稿                   │
├────────────────────────────────────┤
│  [テ]  ┌────────────────────────┐  │
│        │  いまどうしてる？      │  │  ← テキストエリア
│        │                        │  │
│        └────────────────────────┘  │
├────────────────────────────────────┤
│                       280  [投稿]  │  ← 残り文字数カウンター
└────────────────────────────────────┘
```

- Escape キーまたはオーバーレイクリックで閉じる
- 投稿成功後、タイムラインの先頭に即時追加
