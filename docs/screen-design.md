# 画面設計書

## SCR-01 ログイン画面 {#scr-01}

**URL**: `/login`  
**認証**: 不要（認証済みの場合はタイムラインへリダイレクト）

### レイアウト

```
┌─────────────────────────────────────┐
│                                     │
│          RaiseTimeLine              │  ← アプリロゴ
│                                     │
│  ┌───────────────────────────────┐  │
│  │  メールアドレス               │  │  ← テキスト入力
│  └───────────────────────────────┘  │
│  ┌───────────────────────────────┐  │
│  │  パスワード               👁  │  │  ← パスワード入力（表示切替）
│  └───────────────────────────────┘  │
│                                     │
│  ┌───────────────────────────────┐  │
│  │         ログイン              │  │  ← ログインボタン（Primary）
│  └───────────────────────────────┘  │
│                                     │
│      アカウントをお持ちでない方      │
│      → 新規登録はこちら             │  ← SCR-02へのリンク
│                                     │
└─────────────────────────────────────┘
```

### 項目定義

| 要素 | 種別 | 説明 |
|------|------|------|
| メールアドレス | input[type=email] | 必須 |
| パスワード | input[type=password] | 必須、表示/非表示切り替えボタン付き |
| ログインボタン | button | クリックで認証処理を実行 |
| 新規登録リンク | link | SCR-02へ遷移 |

### エラー表示

- 認証失敗時：フォーム上部に「メールアドレスまたはパスワードが正しくありません」を表示

## SCR-02 ユーザー登録画面 {#scr-02}

**URL**: `/register`  
**認証**: 不要

### レイアウト

```
┌─────────────────────────────────────┐
│                                     │
│          RaiseTimeLine              │
│                                     │
│  ┌───────────────────────────────┐  │
│  │  ユーザー名                   │  │
│  └───────────────────────────────┘  │
│  ┌───────────────────────────────┐  │
│  │  メールアドレス               │  │
│  └───────────────────────────────┘  │
│  ┌───────────────────────────────┐  │
│  │  パスワード               👁  │  │
│  └───────────────────────────────┘  │
│  ┌───────────────────────────────┐  │
│  │  パスワード（確認）        👁  │  │
│  └───────────────────────────────┘  │
│                                     │
│  ┌───────────────────────────────┐  │
│  │         アカウント作成        │  │
│  └───────────────────────────────┘  │
│                                     │
│      すでにアカウントをお持ちの方    │
│      → ログインはこちら             │  ← SCR-01へのリンク
│                                     │
└─────────────────────────────────────┘
```

### 項目定義

| 要素 | 種別 | バリデーション |
|------|------|---------------|
| ユーザー名 | input[type=text] | 1〜50文字、英数字・_・- のみ |
| メールアドレス | input[type=email] | メール形式 |
| パスワード | input[type=password] | 8文字以上、英数字混在 |
| パスワード（確認） | input[type=password] | パスワードと一致 |
