# 機能一覧

RaiseTimeLine が提供する機能の一覧。各機能の詳細は個別の機能定義書を参照。

---

## 機能一覧

| 機能ID | 機能名 | 概要 | 詳細 |
|--------|--------|------|------|
| F-01 | ログイン・ユーザー登録 | メールアドレス＋パスワードで認証。JWT トークンを発行 | [auth.md](features/auth.md) |
| F-02 | タイムライン | 全体／フォロー中の2種類をタブ切り替えで表示。新着順 | [timeline.md](features/timeline.md) |
| F-03 | 投稿 | テキスト（280文字）＋画像1枚の投稿・削除。画像は S3 保存 | [post.md](features/post.md) |
| F-04 | コメント | 投稿へのコメント投稿・削除。件数をタイムラインに表示 | [comment.md](features/comment.md) |
| F-05 | いいね | 投稿へのいいね追加・取消。1ユーザー1投稿1回まで | [like.md](features/like.md) |
| F-06 | プロフィール | ユーザー情報の表示・編集。他ユーザーのプロフィールからフォロー操作が可能 | [profile.md](features/profile.md) |
| F-07 | フォロー/フォロワー | フォロー・アンフォロー。フォロー中／フォロワー一覧の表示 | [follow.md](features/follow.md) |
| F-08 | ユーザー検索 | ユーザー名によるインクリメンタル検索。投稿・コメントのユーザー名クリックでもプロフィールへ遷移 | [search.md](features/search.md) |

---

## 機能間の関係

```
[F-01 認証]
  └─ ログイン後、すべての機能を利用可能

[F-02 タイムライン]
  ├─ F-03 投稿カードを表示
  ├─ F-05 いいね操作（タイムライン上で完結）
  ├─ F-04 コメント件数を表示 → クリックで投稿詳細へ
  └─ F-06/F-08 ユーザー名クリックでプロフィールへ遷移

[F-03 投稿]
  ├─ F-04 コメントを受け付ける
  ├─ F-05 いいねを受け付ける
  └─ F-02 タイムラインに表示される

[F-06 プロフィール]
  ├─ F-07 フォロー操作のエントリーポイント
  └─ F-03 そのユーザーの投稿一覧を表示

[F-07 フォロー/フォロワー]
  └─ F-02 フォロー中タイムラインの表示対象を決定

[F-08 ユーザー検索]
  └─ F-06 プロフィール画面へ遷移（フォロー操作も可能）
```

## スコープ外（実装しない機能）

| 機能 | 理由 |
|------|------|
| インプレッション（閲覧数） | 差別化ポイントとして非実装 |
| リツイート / 引用ポスト | 差別化ポイントとして非実装 |
| DM（ダイレクトメッセージ） | スコープ外 |
| 通知機能 | スコープ外 |
| ハッシュタグ / トレンド | スコープ外 |
