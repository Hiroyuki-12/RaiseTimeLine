# 機能定義：タイムライン（F-02）

## 概要

投稿を時系列（新着順）で一覧表示する画面。
**全員タイムライン**と**フォロー中タイムライン**の2種類をタブで切り替えて表示する。

> **実装済み**: 全員タイムライン・フォロー中タイムライン・タブ切り替え・無限スクロール・新着通知。

---

## タイムラインの種類

| 種類 | 表示対象 | 実装状況 |
|------|---------|---------|
| 全員タイムライン | 全ユーザーの投稿 | ✅ 実装済み |
| フォロー中タイムライン | フォロー中ユーザーの投稿のみ（`timeline=following`） | ✅ 実装済み |

---

## 表示項目

各投稿カードに以下を表示する：

| 項目 | 説明 | 実装状況 |
|------|------|---------|
| カラーアバター | ユーザー名のイニシャル + ユーザー固有カラーの丸アイコン | ✅ |
| 表示名 | 投稿者の displayName | ✅ |
| @ハンドル | 投稿者の @username | ✅ |
| 投稿日時 | 相対表示（例：3分前、2時間前、1日前） | ✅ |
| 投稿テキスト | 本文（改行・長文対応） | ✅ |
| いいね数 | 🤍/❤️ アイコン＋件数（クリックでいいね切り替え。楽観的更新） | ✅ |
| コメント数 | 💬 アイコン＋件数（クリックで投稿詳細画面へ遷移） | ✅ |
| 編集ボタン（✏️） | 投稿者本人のみ表示 | ✅ |
| 削除ボタン（🗑️） | 投稿者本人のみ表示 | ✅ |

---

## 操作

| 操作 | 動作 | 実装状況 |
|------|------|---------|
| タブ切り替え | 全員 ↔ フォロー中 | ✅ |
| 投稿欄クリック / 「投稿する」ボタン | 投稿作成モーダルを開く | ✅ |
| スクロール末尾到達 | 次ページを自動取得（Intersection Observer） | ✅ |
| 「さらに読み込む」ボタン | 次ページを手動取得（フォールバック） | ✅ |
| 新着バナークリック | タイムラインを最新状態にリセット | ✅ |

---

## 投稿の並び順

- 新着順（`created_at` の降順）
- 1ページあたり20件（`GET /api/posts?page=0&size=20`）
- Intersection Observer により スクロール末尾から200px手前で次ページを先読み
- 「さらに読み込む」ボタンによるフォールバック

---

## 新着通知（ポーリング）

- タイムライン初回ロード後、30秒ごとに新着件数を確認
- 新着があれば「N件の新しい投稿を見る」バナーを上部に表示
- バナークリックでタイムラインをリセットして最新状態に更新
- API: `GET /api/posts/new-count?since=<ISODateTime>`

---

## API一覧

| Method | Path | 説明 | レスポンス |
|--------|------|------|---------|
| GET | `/api/posts?page=0&size=20&timeline=all` | 全員タイムライン取得（ページネーション付き） | 200 `PostResponse[]` |
| GET | `/api/posts?page=0&size=20&timeline=following` | フォロー中タイムライン取得（フォロー中ユーザーの投稿のみ） | 200 `PostResponse[]` |
| GET | `/api/posts/new-count?since=ISO` | 指定日時以降の新着件数 | 200 `{ count: N }` |

> `timeline` は省略時 `all`。`following` を指定すると、ログインユーザーがフォロー中のユーザーの投稿のみを返す。

---

## 自分の投稿の場合

- 投稿カードに編集（✏️）・削除（🗑️）アイコンを表示
- 削除: カスタム確認モーダル（ConfirmModal）で確認後に削除
- 編集: インライン編集モードで本文を書き換え
