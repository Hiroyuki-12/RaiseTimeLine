# 機能定義：タイムライン（F-02）

## 概要

投稿を時系列（新着順）で一覧表示する画面。
**全体タイムライン**と**フォロー中タイムライン**の2種類をタブで切り替えて表示する。

---

## タイムラインの種類

| 種類 | 表示対象 | 未フォロー時 |
|------|---------|------------|
| 全体タイムライン | 全ユーザーの投稿 | 通常表示 |
| フォロー中タイムライン | フォロー中ユーザーの投稿のみ | 「まだフォローしているユーザーがいません」と表示 |

---

## 表示項目

各投稿カードに以下を表示する：

| 項目 | 説明 |
|------|------|
| アバター画像 | 投稿者のプロフィール画像（クリックでプロフィール画面へ遷移） |
| ユーザー名 | 投稿者のユーザー名（クリックでプロフィール画面へ遷移） |
| 投稿日時 | 相対表示（例：3分前、2時間前）、ホバーで絶対日時を表示 |
| 投稿テキスト | 本文（改行・URLをそのまま表示） |
| 投稿画像 | 画像がある場合のみ表示（クリックで拡大） |
| いいね数 | いいねアイコン＋件数。自分がいいね済みの場合はアイコン色を変更 |
| コメント数 | コメントアイコン＋件数（クリックで投稿詳細画面へ遷移） |

---

## 操作

| 操作 | 動作 |
|------|------|
| タブ切り替え | 全体 ↔ フォロー中 を切り替える |
| ユーザー名 / アバタークリック | プロフィール画面（SCR-05）へ遷移 |
| いいねボタンクリック | いいねを追加 / 取消（即時反映） |
| コメントアイコンクリック | 投稿詳細画面（SCR-04）へ遷移 |
| 投稿カードクリック | 投稿詳細画面（SCR-04）へ遷移 |
| 投稿作成ボタンクリック | 投稿作成モーダルを開く |

---

## 投稿の並び順

- 新着順（`created_at` の降順）
- ページネーション or 無限スクロールで追加読み込み

---

## 自分の投稿の場合

- 投稿カードに「削除」ボタンを追加表示する
- 削除ボタンクリック → 確認ダイアログ → 削除実行
