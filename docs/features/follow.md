# 機能定義：フォロー/フォロワー（F-07）

## 概要

他のユーザーをフォロー・アンフォローする機能。
フォロー中のユーザーの投稿はフォロー中タイムラインに表示される。
フォロー中・フォロワーの一覧を確認できる。

---

## フォロー

### 条件

- ログイン済みユーザーのみ実行可能
- 自分自身はフォローできない
- 同一ユーザーへの重複フォローはできない（DB の UNIQUE 制約で保証）

### 処理フロー

1. 他ユーザーのプロフィール画面で「フォローする」ボタンをクリック
2. バックエンドAPIへフォローリクエスト送信
3. `follows` テーブルへ `(follower_id, followee_id)` を保存
4. ボタン表示を「フォローする」→「フォロー中」に変更
5. 相手のフォロワー数を +1、自分のフォロー数を +1 して即時反映

---

## アンフォロー

### 処理フロー

1. フォロー中のユーザーのプロフィール画面で「フォロー中」ボタンをクリック
2. 確認ダイアログを表示（「@username のフォローを解除しますか？」）
3. バックエンドAPIへアンフォローリクエスト送信
4. `follows` テーブルから該当レコードを物理削除
5. ボタン表示を「フォロー中」→「フォローする」に変更
6. 相手のフォロワー数を -1、自分のフォロー数を -1 して即時反映

---

## フォロー中一覧・フォロワー一覧

### 表示場所

プロフィール画面（SCR-05）のフォロー数・フォロワー数をクリックすると
フォロー一覧画面（SCR-06）へ遷移する。

### 表示項目（各ユーザー行）

| 項目 | 説明 |
|------|------|
| アバター画像 | ユーザーのプロフィール画像（クリックでプロフィール画面へ遷移） |
| ユーザー名 | ユーザー名（クリックでプロフィール画面へ遷移） |
| フォロー/アンフォローボタン | 自分自身の行には表示しない |

### タブ切り替え

- **フォロー中タブ**: 自分がフォローしているユーザー一覧
- **フォロワータブ**: 自分をフォローしているユーザー一覧

---

## フォローデータ属性

| カラム | 型 | 必須 | 説明 |
|-------|---|------|------|
| id | BIGINT | ○ | 主キー（AUTO_INCREMENT） |
| follower_id | BIGINT | ○ | フォローする側（FK: users.id） |
| followee_id | BIGINT | ○ | フォローされる側（FK: users.id） |
| created_at | TIMESTAMP | ○ | フォロー日時（サーバー自動設定） |

**インデックス**
- UNIQUE: `(follower_id, followee_id)` — 重複フォローをDB層で防止
- INDEX: `follower_id` — フォロー中一覧取得を高速化
- INDEX: `followee_id` — フォロワー一覧取得を高速化
