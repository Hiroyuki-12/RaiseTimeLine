# 機能定義：ユーザー検索（F-08）

## 概要

ユーザー名でユーザーを検索する機能。
専用の検索画面でのインクリメンタル検索に加え、
タイムライン・投稿詳細・コメント欄のユーザー名クリックからもプロフィールへ直接遷移できる。

---

## ユーザー名検索（検索画面）

### 検索仕様

| 項目 | 内容 |
|------|------|
| 検索対象 | ユーザー名（username）の前方一致または部分一致 |
| 検索タイミング | インクリメンタル検索（入力のたびにAPIを呼び出す） |
| デバウンス | 300ms（連続入力時のAPI呼び出しを抑制） |
| 最小入力文字数 | 1文字以上で検索開始 |
| 未入力時 | 検索結果を表示しない |

### 検索結果表示項目（各ユーザー行）

| 項目 | 説明 |
|------|------|
| アバター画像 | ユーザーのプロフィール画像 |
| ユーザー名 | `@username` 形式で表示 |
| フォロー/アンフォローボタン | 自分自身の場合は表示しない |

### 操作

| 操作 | 動作 |
|------|------|
| ユーザー行クリック | プロフィール画面（SCR-05）へ遷移 |
| フォローボタンクリック | フォロー追加（遷移なし・その場で更新） |
| アンフォローボタンクリック | フォロー解除（遷移なし・その場で更新） |

### 検索結果なし

「`{入力キーワード}` に一致するユーザーが見つかりませんでした」と表示する。

---

## ユーザー名クリックによるプロフィール遷移

検索画面を経由せず、以下の箇所からユーザーのプロフィール画面へ直接遷移できる。

| 遷移元 | 操作 |
|--------|------|
| タイムライン（SCR-03） | 投稿カードのアバター画像またはユーザー名をクリック |
| 投稿詳細画面（SCR-04） | 投稿のアバター画像またはユーザー名をクリック |
| コメント欄（SCR-04） | コメントのアバター画像またはユーザー名をクリック |
| フォロー一覧画面（SCR-06） | 一覧の行をクリック |

遷移先：プロフィール画面（SCR-05）  
プロフィール画面ではフォロー/アンフォロー操作が可能。
