# 機能定義：プロフィール（F-06）

## 概要

ユーザーの情報を表示・編集する機能。
自分のプロフィールは編集可能。他ユーザーのプロフィールではフォロー/アンフォロー操作ができる。
投稿・コメントのユーザー名クリックからもプロフィール画面へ遷移できる。

---

## プロフィール表示

### 表示項目

| 項目 | 説明 |
|------|------|
| アバター画像 | プロフィール画像（未設定の場合はデフォルト画像） |
| ユーザー名 | `@username` 形式で表示 |
| 自己紹介 | bio（未設定の場合は非表示） |
| フォロー数 | フォロー中のユーザー数（クリックでフォロー一覧画面へ遷移） |
| フォロワー数 | フォロワーのユーザー数（クリックでフォロー一覧画面へ遷移） |
| 投稿一覧 | そのユーザーの投稿を新着順で表示 |

### 自分のプロフィール表示時

- 「プロフィールを編集」ボタンを表示
- フォロー/アンフォローボタンは表示しない

### 他ユーザーのプロフィール表示時

- フォロー中の場合：「フォロー中」ボタン（クリックでアンフォロー）
- 未フォローの場合：「フォローする」ボタン（クリックでフォロー）
- 「プロフィールを編集」ボタンは表示しない

---

## プロフィール遷移パターン

プロフィール画面へは以下の操作から遷移できる：

| 遷移元 | 操作 |
|--------|------|
| タイムライン | 投稿カードのアバター画像またはユーザー名をクリック |
| 投稿詳細画面 | 投稿のアバター画像またはユーザー名をクリック |
| コメント欄 | コメントのアバター画像またはユーザー名をクリック |
| ユーザー検索結果 | 検索結果の行をクリック |
| フォロー/フォロワー一覧 | 一覧の行をクリック |
| ナビゲーションバー | 自分のアバター画像をクリック（自分のプロフィール） |

---

## プロフィール編集

### 条件

- 自分のプロフィールのみ編集可能

### 編集可能項目

| 項目 | 型 | 必須 | バリデーション |
|------|---|------|---------------|
| ユーザー名 | 文字列 | ○ | 1〜50文字、英数字・アンダースコア・ハイフンのみ、重複不可 |
| 自己紹介 | 文字列 | － | 0〜160文字 |
| アバター画像 | ファイル | － | JPEG / PNG、最大2MB |

### 処理フロー

1. 「プロフィールを編集」ボタンをクリックし、編集モーダルを開く
2. 各項目を編集
3. アバター画像を変更する場合：S3にアップロード → URLを取得
4. 「保存」ボタンをクリック
5. バックエンドAPIへ更新リクエスト送信
6. `users` テーブルを更新
7. プロフィール画面に反映

### エラーケース

| ケース | 対応 |
|--------|------|
| ユーザー名重複 | 400 Bad Request、「すでに使用されているユーザー名です」を表示 |
| ユーザー名バリデーション違反 | 入力欄にエラーメッセージを表示 |
| 画像形式不正 | 「対応していないファイル形式です」を表示 |
| 画像サイズオーバー | 「ファイルサイズが大きすぎます（2MBまで）」を表示 |

---

## ユーザーデータ属性

| カラム | 型 | 必須 | 説明 |
|-------|---|------|------|
| id | BIGINT | ○ | 主キー（AUTO_INCREMENT） |
| email | VARCHAR(255) | ○ | メールアドレス（UNIQUE） |
| password_hash | VARCHAR(255) | ○ | BCryptハッシュ |
| username | VARCHAR(50) | ○ | ユーザー名（UNIQUE） |
| avatar_url | TEXT | － | S3アバター画像URL（NULLの場合デフォルト画像） |
| bio | VARCHAR(160) | － | 自己紹介 |
| created_at | TIMESTAMP | ○ | 作成日時（サーバー自動設定） |
| updated_at | TIMESTAMP | ○ | 更新日時（サーバー自動設定） |
