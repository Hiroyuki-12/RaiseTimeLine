# 機能定義：投稿（F-03）

## 概要

テキスト（最大280文字）を投稿する機能。
投稿はタイムラインに表示され、投稿者本人のみ編集・削除できる。

> **実装済み**: テキスト投稿・編集・削除。画像添付は今後実装予定。

---

## 投稿作成

### 入力項目

| 項目 | 型 | 必須 | バリデーション |
|------|---|------|---------------|
| テキスト | 文字列 | ○ | 1〜280文字 |

### 処理フロー

1. サイドバーの「投稿する」ボタン または タイムライン上部の投稿欄をクリック
2. モーダルが開く
3. テキストを入力（1〜280文字）
4. 「投稿」ボタンをクリック
5. `posts` テーブルへ保存
6. タイムラインの先頭に即時追加（楽観的更新）

### API

| Method | Path | 認証 | リクエスト | レスポンス |
|--------|------|------|----------|---------|
| POST | `/api/posts` | JWT必須 | `{ content: string }` | 201 `PostResponse` |

### エラーケース

| ケース | 対応 |
|--------|------|
| テキスト未入力 | 投稿ボタンをdisabledにする |
| 文字数オーバー（281文字以上） | リアルタイムで文字数カウントを赤く表示、投稿ボタンをdisabled |
| 未認証 | 401 エラー |

---

## 投稿編集

### 条件

- 編集できるのは投稿者本人のみ
- 他ユーザーの投稿には編集ボタン（✏️）を表示しない

### 処理フロー

1. 投稿カードの編集ボタン（✏️）をクリック
2. インライン編集モードに切り替わる
3. テキストを変更して「保存」をクリック
4. バックエンドへ更新リクエスト
5. タイムライン上のカードを更新後内容に差し替え

### API

| Method | Path | 認証 | リクエスト | レスポンス |
|--------|------|------|----------|---------|
| PUT | `/api/posts/{id}` | JWT必須 | `{ content: string }` | 200 `PostResponse` |

### エラーケース

| ケース | HTTPステータス | メッセージ |
|--------|-------------|---------|
| 他ユーザーの投稿を編集しようとした | 403 | このポストを編集する権限がありません |
| 投稿が存在しない | 404 | ポストが見つかりません |

---

## 投稿削除

### 条件

- 削除できるのは投稿者本人のみ
- 他ユーザーの投稿には削除ボタン（🗑️）を表示しない

### 処理フロー

1. 投稿カードの削除ボタン（🗑️）をクリック
2. `window.confirm` で確認ダイアログを表示
3. 「OK」をクリック後、バックエンドAPIへ削除リクエスト送信
4. `posts` テーブルから物理削除
5. タイムラインから該当投稿を即時除去

### API

| Method | Path | 認証 | レスポンス |
|--------|------|------|---------|
| DELETE | `/api/posts/{id}` | JWT必須 | 204 No Content |

### エラーケース

| ケース | HTTPステータス | メッセージ |
|--------|-------------|---------|
| 他ユーザーの投稿を削除しようとした | 403 | このポストを削除する権限がありません |
| 投稿が存在しない | 404 | ポストが見つかりません |

---

## PostResponse（レスポンス形式）

```json
{
  "id": 1,
  "content": "投稿テキスト",
  "authorId": 2,
  "authorUsername": "testuser01",
  "authorDisplayName": "テストユーザー",
  "createdAt": "2026-05-06T15:30:00",
  "updatedAt": "2026-05-06T15:30:00"
}
```

---

## 投稿データ属性（posts テーブル）

| カラム | 型 | 必須 | 説明 |
|-------|---|------|------|
| id | BIGSERIAL | ○ | 主キー（自動採番） |
| user_id | BIGINT | ○ | 投稿者（FK: users.id, CASCADE DELETE） |
| content | VARCHAR(280) | ○ | 投稿テキスト |
| created_at | TIMESTAMP | ○ | 投稿日時（DB側で NOW() 自動設定） |
| updated_at | TIMESTAMP | ○ | 更新日時（DB側で NOW() 自動設定） |
