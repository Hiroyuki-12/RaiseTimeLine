# 機能定義：投稿（F-03）

## 概要

テキストと画像（任意・1枚まで）を投稿する機能。
投稿はタイムラインに表示され、本人のみ削除できる。

---

## 投稿作成

### 入力項目

| 項目 | 型 | 必須 | バリデーション |
|------|---|------|---------------|
| テキスト | 文字列 | ○ | 1〜280文字 |
| 画像 | ファイル | － | JPEG / PNG / GIF、最大5MB、1枚まで |

### 処理フロー

1. 投稿作成ボタンをクリックし、モーダルを開く
2. テキストを入力（必須）、画像を添付（任意）
3. 「投稿する」ボタンをクリック
4. 画像がある場合：バックエンド経由でAWS S3にアップロード → S3のURLを取得
5. テキスト＋画像URLを `posts` テーブルへ保存
6. タイムラインの先頭に新しい投稿を表示

### エラーケース

| ケース | 対応 |
|--------|------|
| テキスト未入力 | 投稿ボタンをdisabledにする |
| 文字数オーバー（281文字以上） | リアルタイムで文字数カウントを赤く表示、投稿ボタンをdisabled |
| 画像形式不正 | 「対応していないファイル形式です」メッセージを表示 |
| 画像サイズオーバー（5MB超） | 「ファイルサイズが大きすぎます（5MBまで）」メッセージを表示 |
| アップロード失敗 | 「投稿に失敗しました。再試行してください」メッセージを表示 |

---

## 投稿削除

### 条件

- 削除できるのは投稿者本人のみ
- 他ユーザーの投稿には削除ボタンを表示しない

### 処理フロー

1. 投稿カードの「削除」ボタンをクリック
2. 確認ダイアログを表示（「この投稿を削除しますか？」）
3. 確認後、バックエンドAPIへ削除リクエスト送信
4. `posts` テーブルから物理削除
5. 紐づく `comments`・`likes` も連鎖削除（CASCADE）
6. S3上の画像も削除
7. タイムラインから該当投稿を除去

---

## 画像ストレージ（AWS S3）

| 項目 | 内容 |
|------|------|
| 保存先 | AWS S3 バケット |
| ファイル名 | `posts/{post_id}/{uuid}.{拡張子}` |
| アクセス | 署名付きURLまたはパブリック読み取り |
| 削除タイミング | 投稿削除時に同時削除 |

---

## 投稿データ属性

| カラム | 型 | 必須 | 説明 |
|-------|---|------|------|
| id | BIGINT | ○ | 主キー（AUTO_INCREMENT） |
| user_id | BIGINT | ○ | 投稿者（FK: users.id） |
| content | VARCHAR(280) | ○ | 投稿テキスト |
| image_url | TEXT | － | S3画像URL（画像なし時はNULL） |
| created_at | TIMESTAMP | ○ | 作成日時（サーバー自動設定） |
| updated_at | TIMESTAMP | ○ | 更新日時（サーバー自動設定） |
